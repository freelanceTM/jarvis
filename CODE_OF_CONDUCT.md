# Code of Conduct

## Our standard

Be professional and respectful. This is a personal product built in public
view; contributors, users and the owner communicate here.

Expected behavior:

- technical criticism targets code and decisions, not people;
- assume good faith; ask before accusing;
- keep discussions in the repository language the thread started in
  (Russian or English are both fine);
- no spam, advertising, or off-topic flooding;
- no harassment, hate speech, personal attacks, or doxxing — ever;
- no posting of secrets, license codes, other people's personal data,
  or real user prompts/speech anywhere in the project.

## Scope

Applies to the repository (issues, PRs, discussions), and any project-run
community space.

## Enforcement

The repository owner (GitHub: **freelanceTM**) is the sole maintainer and
enforcer. Violations may be edited, locked, deleted, or lead to blocking
from the repository. Reports of violations go privately to the owner via
GitHub (or the vulnerability-reporting channel if sensitive).

This policy is a short project-specific code of conduct modeled on the
Contributor Covenant; it does not create any legal entity, warranty, or
obligation beyond the repository itself.
